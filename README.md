# AVIATION | Business & Consulting Agency

Professional single-page website for the agency.

## Live site
After GitHub Pages is enabled:  
**https://samyfarag60.github.io/aviation-agency/**

## How to enable GitHub Pages
1. Go to the repository: https://github.com/Samyfarag60/aviation-agency
2. Click **Settings** → **Pages**
3. Under **Source**, choose **Deploy from a branch**
4. Select branch **main** and folder **/ (root)**
5. Click **Save**
6. Wait 1–2 minutes — the site will be live at the URL above.

## Editing
Edit `index.html` and push changes. The live site updates automatically.
